# LLM-powered Chat for Document Exploration

## Setup

### Prerequisites
- Node.js
- OpenAI API Key

### Backend
1. Navigate to `server` directory.
2. Create `.env` file with `OPENAI_API_KEY`.
3. Run `npm run dev` (ensure `nodemon` is installed or use `npx nodemon`).
   - I need to add `dev` script to `package.json`.

### Frontend
1. Navigate to `client` directory.
2. Run `npm run dev`.

## Features
- Upload PDF
- Chat with context
- (In Progress) NER, Summarization
